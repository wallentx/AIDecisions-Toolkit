# AIDecisions-Toolkit v0.1.0

First published release. The suite and all five tools start at version 0.1.0;
earlier local 0.2.0 through 0.6.0 snapshots were development versions.

- `AID.diff`: configurable model-assisted code-change assessment.
- `AID.discover`: bounded history evidence for agent-led tool discovery.
- `AID.pr` and `AID.ci`: read-only GitHub evidence with completeness metadata.
- `AID.runtime`: bounded static AArch64 ELF facts on Linux and Android hosts.
- `AID`: tool discovery, native builds, skill installation, and source updates.

Native ZIP archives include all six executables, documentation, per-binary
checksums, and build provenance. Choose the archive matching your OS and
architecture. Keep its executables together and run `AID --init` after placing
them in the intended installation directory.

Termux users should build the source archive with the native Go toolchain:
`go run ./cmd/aid-build`. Linux archives are not Android executables.
`AID.runtime` reports host inspection as unavailable on macOS and Windows.

CI tests Go and Python code, runs Go vet, and builds/verifies native executables
on Linux, macOS, and Windows. A separate job tests the minimum Go version.
`SHA256SUMS` covers the downloadable archives; each native ZIP also includes
`build-info.json` with its source commit, Go version, platform, and workflow run.
